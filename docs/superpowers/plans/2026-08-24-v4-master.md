# Concursos Watch v4 Master Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** coordenar a implementação da v4 híbrida sem misturar responsabilidades nem promover qualquer subsistema antes de seus gates próprios passarem.

**Architecture:** a implementação foi dividida em quatro planos independentes porque filtragem Python, edge Rust, dashboard Android e publicação/CI são subsistemas revisáveis separadamente. A ordem abaixo minimiza risco: primeiro impedir lixo na origem, depois construir a API read-only, depois integrar a Home dinâmica no Android e por fim fechar a publicação/rollout.

**Tech Stack:** Python, Rust/WASM, Cloudflare D1/Workers, Kotlin/Compose/WebView, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-08-24-concursos-watch-v4-final-design.md`

## Global Constraints

- O spec final de 2026-08-24 prevalece sobre documentos v3/v4 anteriores.
- Nenhum merge para `main` antes de CI geral, Android build, segurança da WebView e visual QA verdes.
- Nenhum endpoint público de escrita deve permanecer no estado final.
- Licitação/pregão/navegação institucional devem ser bloqueados antes do D1 público.
- Toda mudança dinâmica de dashboard exige QA visual antes da promoção.
- Rollout deve ser reversível em cada fronteira: dados, dashboard, Rust e APK.

### Task 2: Rust Edge

**Plan:** `docs/superpowers/plans/2026-08-24-v4-rust-edge.md`

- [ ] Criar Worker Rust isolado.

- [ ] Ler somente `ACCEPTED` do D1.

- [ ] Renderizar dashboard declarativo.

**Migration correction locked by this master plan:** a evolução do D1 deve usar `cloudflare/migrations/0002_v4.sql` para bancos existentes e também atualizar `cloudflare/schema.sql` para instalações novas. Não executar `ALTER TABLE ... ADD COLUMN` repetidamente em todo deploy.

**Exit gate:** staging Rust atende `/health`, `/api/v1/contests`, `/api/v1/dashboard-manifest` e `/dashboard`; `/api/v1/ingest` não existe.
