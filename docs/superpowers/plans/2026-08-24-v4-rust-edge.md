# Concursos Watch v4 Rust Edge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** substituir a API pública mutável em JavaScript por um Worker Rust/WASM read-only que serve somente dados aceitos, filtros explícitos e o dashboard HTML/CSS seguro.

**Architecture:** o Worker Rust lê D1 e não possui endpoint público de ingestão. O dashboard é renderizado a partir de `DashboardConfig` declarativa e dados canônicos. A migração ocorre em paralelo ao Worker JS atual: primeiro Rust em rota/staging, depois smoke test, depois cutover.

**Tech Stack:** Rust stable, `worker`/workers-rs, Cloudflare Workers/WASM, D1, serde, sha2, HTML escaping, Wrangler.

**Spec:** `docs/superpowers/specs/2026-08-24-concursos-watch-v4-final-design.md`

## Global Constraints

- API pública é read-only.
- Somente registros aceitos aparecem em `/api/v1/contests`.
- Todas as queries são parametrizadas.
- Dashboard sem JavaScript.
- CSP e cabeçalhos definidos no spec são obrigatórios.
- `DashboardConfig` não armazena HTML arbitrário.
- O Worker JS antigo só é removido depois de smoke tests verdes no Rust.
